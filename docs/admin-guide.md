# TourLatam 2026 - Admin CMS User Guide

## Accessing the Backoffice
- **URL**: `http://localhost:3000/admin/login`
- **Default Admin Account**: `admin@tourlatam.org` / `Admin123!`
- **Default Editor Account**: `editor@tourlatam.org` / `Editor123!`

## Modules Overview
1. **Dashboard**: Live metrics of speakers, sponsors, agenda items, and audit log activity.
2. **Event Settings**: Modify event dates, venue, city, CTAs, and Google Analytics tracking IDs without touching code.
3. **Page Builder**: Reorder sections and toggle visibility for the public landing.
4. **Speakers**: Add speakers, upload photos, set specialties, link videos.
5. **Sponsors**: Manage sponsors and their sponsorship tiers.
6. **Agenda**: Schedule keynotes, panels, workshops, and assign speakers.
7. **Pricing / Tickets**: Manage registration tiers, prices, and perks.
8. **Media Library**: Upload and manage brand assets.
9. **User Management** (Admin Only): Create users and assign RBAC roles (`ADMIN` vs `EDITOR`).
